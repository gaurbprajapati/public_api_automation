DESIGN DIRECTION

- Bold editorial theme
- Strong burgundy accent (#7b1d1d) header banner, off-white background, Cormorant Garamond + Outfit fonts
- Large dramatic name treatment
- Strong typographic hierarchy
- Profile Picture: If provided, show it left of the candidate name in a circular layout; if absent, do not reserve space and keep the name/details left aligned
- Do not add margin on any side of the page

CONTENT RULES

- If summary data is present, open with a refined 3-sentence executive summary (not in a passage) written in elevated third-person perspective that matches the bold editorial tone; else dont include the section
- Keep the section name with color (#7b1d1d) and subheadings of bold black tone
- Prioritize narrative-led impact statements over dense metric stacking; include numbers, but let each role tell a clear strategic story
- Write Work History in tight, high-signal bullet points (keep 4 points per role)
- Use precise, outcome-driven language (avoid generic adjectives like "excellent," "dynamic," "results-driven")
- Inlcude skills side by side in round pills style
- Use consistent, accessible, and readable font sizing across sections for a professional outlook with proper fitting
- use bullets for certifications
- Maintain consistent bullets/punctuation style across all sections
