DESIGN DIRECTION

- Clean minimal theme with forest green (#1e4d3b) header banner and cream white background (#fefdf9) for body
- Font pairing: Lora (headings) + Nunito (body)
- Lightweight layout with consistent section spacing
- Section titles: simple, forest green color (#1e4d3b)
- No lines, borders, dividers, or decorative elements anywhere
- Profile Picture: If provided, display at top-left in a circular layout; if absent, do not reserve space
- Header Alignment: Center-align name, title, and details if a profile picture exists; otherwise, left-align
- No margin on page edges

CONTENT RULES

- Summary: Include only if present in source; rewrite into exactly 1 passage of 3 lines in first person perspective
- Work History: Convert existing content into bullet points ONLY if descriptive data exists; otherwise show only role, company, and dates.
- Maintain visual distinction between role name and content in work history.
- Bullet Format (fixed): Each bullet must be a single sentence, max 4 lines, starting with an action verb and written in past tense
- Bullet Prefix: Use a simple dash (-) as prefix
- Bullet Count: Reflect only available data; do not force a specific number
- Skills: Display simple inline grouped format (no pills, no tags, no heavy styling)
- Certifications/Education: Use simple indentation and round bullets for sub-points.
- Punctuation: All bullets must end with a period
